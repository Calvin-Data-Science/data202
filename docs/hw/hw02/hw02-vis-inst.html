Exercise 5: Overplotting

The following plot attempts to show how temperature affects ridership. However, it suffers from overplotting.

ggplot(hourly_rides, aes(x = temp, y = rides)) +
  geom_point() +
  facet_wrap(~ member_type) + 
  labs(x = "Normalized temperature", y = "Rides")

Pick at least two of the following methods to try to fix the overplotting issue. Which do you prefer, and why? Include the code and results of both plots you tried.

  • geom_density_2d
  • Making points transparent (alpha = 0.05) or very small (shape = '.')
  • binning the x axis (group = cut_width(temp, ___))
  • any other approach you want to try!
