# What Is Machine Learning?

Machine learning is the process of building models that learn patterns from data to make predictions or decisions.

- Inputs: data
- Process: training + evaluation
- Outputs: predictions + insights

---

# Typical Workflow

1. Define the question
2. Collect and clean data
3. Split train and test sets
4. Train baseline and improved models
5. Evaluate with appropriate metrics
6. Communicate results and limits

---

# Supervised Learning

- Regression: predict numeric values
- Classification: predict categories

Examples:
- House price prediction
- Spam detection
- Churn prediction

---

# Unsupervised Learning

- Clustering: find groups in data
- Dimensionality reduction: summarize features

Examples:
- Customer segmentation
- Pattern discovery in unlabeled datasets

---

# Evaluation Matters

Use the right metric for the task:

- Regression: MAE, RMSE, $R^2$
- Classification: accuracy, precision, recall, F1

Always compare against a baseline model.

---

# Responsible ML

- Data can encode bias
- Models can amplify inequities
- Predictions are not certainty

Good practice:
- Document assumptions
- Test for fairness concerns
- Explain uncertainty
