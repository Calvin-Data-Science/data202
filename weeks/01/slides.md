# Introduction to Machine Learning

### DATA 202 · Week 1

---

## What is Machine Learning?

> "A computer program is said to learn from experience E with respect to some class of tasks T and performance measure P, if its performance at tasks in T, as measured by P, improves with experience E."
> — Tom Mitchell

---

## Traditional Programming vs. ML

| Traditional | Machine Learning |
|---|---|
| Rules + Data → Output | Data + Output → Rules |
| We write the logic | The model learns the logic |

---

## Categories of ML

- **Supervised learning** — labeled examples (input → label)
- **Unsupervised learning** — no labels; find structure
- **Reinforcement learning** — learn from feedback/reward

---

## The ML Workflow

1. Frame the problem
2. Collect & explore data
3. Prepare features
4. Choose & train a model
5. Evaluate & iterate
6. Deploy & monitor
