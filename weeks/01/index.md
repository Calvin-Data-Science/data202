## Learning Objectives

By the end of this week, students will be able to:

- Have an idea of what machine learning is and how we are studying this in this course
- Set up and start using the tools for the course
- Remember some core Python programming concepts (lists, tuples, dicts, NumPy arrays)
- **02A** — Manipulate the structure and contents of pandas DataFrames by accessing, adding, and deleting rows and columns
- **02B** — Sort, filter, and query DataFrames to find and highlight specific information
